மீடியா கோப்புகள் இணைக்கும் வழிமுறை (How to use Media)

நீங்கள் உங்கள் கம்ப்யூட்டரில் உள்ள வீடியோ அல்லது ஆடியோவின் Copy Path-ஐ கீழே உள்ள Input box-ல் Paste செய்யலாம் அல்லது நேரடியாக இந்த கோப்பின் (media.html) கோடிங்கில் உள்ள media ஆப்ஜெக்ட்டில் கொடுத்து Play செய்து கொள்ளலாம்.

🎥

வீடியோ பிளேயர் (Video Player)

MP4, WebM, MOV அல்லது Online Video URL
Ready
🎥 தற்போதைய Path: இன்னும் இணைக்கப்படவில்லை
Video Copy Path அல்லது URL-ஐ Paste செய்யவும்: media.video

💡 வழிமுறை: VS Code-ல் உங்கள் வீடியோ file மீது Right Click ➔ Copy Relative Path அல்லது Copy Path கிளிக் செய்து இங்கே Paste செய்து Play-ஐ அழுத்தவும்.

💡 வழிமுறை: VS Code-ல் உங்கள் பாடல் file மீது Right Click ➔ Copy Relative Path அல்லது Copy Path கிளிக் செய்து இங்கே Paste செய்யவும்.

💻 கோடிங்கில் நேரடியாக Path அமைப்பது எப்படி? (Coding Configuration)

இந்த media.html கோப்பின் ஸ்கிரிப்டில் உள்ள media ஆப்ஜெக்ட்டில் உங்கள் Video மற்றும் Audio path-ஐ கீழே உள்ளது போல் மாற்றினால் போதும்: 

// ================================================================
// 🎬 MEDIA CONFIGURATION / மீடியா அமைப்புகள்
// ================================================================
const media = {
  // 🎥 1. உங்கள் Video File Path அல்லது URL-ஐ இங்கே Paste செய்யவும்:
  video: "media/sample_video.mp4",

  // 🔊 2. உங்கள் Audio File Path அல்லது URL-ஐ இங்கே Paste செய்யவும்:
  audio: "media/sample_audio.wav"
};
